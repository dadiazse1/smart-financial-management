# Smart Financial Management

## Publicación en GitHub Pages

Este paquete contiene la versión con mejoras de diseño adaptable (responsive).

### Archivos
- `index.html`: aplicación web con ajustes para escritorio, tabletas y teléfonos.
- `README.md`: estas instrucciones.

### Actualizar el repositorio
1. Descomprime el ZIP.
2. Abre el repositorio `smart-financial-management` en GitHub.
3. Entra en la carpeta `docs`.
4. Reemplaza únicamente `index.html` por el incluido en este paquete.
5. Conserva los demás archivos existentes, incluido `PROJECT_ROADMAP.md`.
6. Pulsa **Commit changes** y espera a que GitHub Pages termine de publicar.
7. Abre la web y recarga con `Ctrl + Shift + R`.

### Qué cambia
- Menú lateral desplegable en pantallas pequeñas.
- Tarjetas y paneles reorganizados para tabletas y móviles.
- Formularios que se adaptan al ancho disponible.
- Tablas con desplazamiento horizontal dentro de su contenedor, sin ensanchar toda la página.
- Prevención del desbordamiento horizontal general.

Los datos de demostración y el funcionamiento de los módulos se mantienen. La validación final debe hacerse en un teléfono y en una tableta reales o mediante las herramientas de dispositivo del navegador.
